# Vesttor

[Português](#português) · [English](#english)

## Português

Estudo acadêmico de controle financeiro pessoal, desenvolvido no Projeto A da faculdade com HTML, CSS, JavaScript e Firebase.

A escolha por não utilizar frameworks teve como objetivo aprender os fundamentos do desenvolvimento web. Motivado pela busca por uma melhor organização financeira, este estudo deu origem ao **Vesttor Vite**.

### O que foi explorado

- Construção de interfaces e interação com o DOM usando JavaScript.
- Autenticação com Firebase Authentication.
- Persistência de dados com Cloud Firestore.
- Cadastro, consulta, edição e exclusão de transações financeiras.
- Organização de categorias e formas de pagamento.
- Registro de parcelas e apresentação de totais financeiros.

### Tecnologias

HTML · CSS · JavaScript · Firebase Authentication · Cloud Firestore

### Estrutura e execução

A interface está em `public/`. O repositório também contém configurações do Firebase e arquivos de experimentação.

Para explorar o estudo, clone o repositório, revise a configuração do Firebase e sirva a pasta `public/` com um servidor HTTP local. Os fluxos de autenticação e dados dependem de um projeto Firebase configurado, dos serviços habilitados e das respectivas regras de acesso.

### Estágio do projeto

Este repositório preserva a versão acadêmica inicial. As funcionalidades representam o escopo explorado no código e não uma aplicação financeira completa ou pronta para produção. A execução depende da configuração do ambiente e dos serviços externos.

## English

An academic study of personal finance management, developed for the university's Projeto A course using HTML, CSS, JavaScript, and Firebase.

I chose to work without frameworks to learn the fundamentals of web development. Motivated by the need to better organize personal finances, this study became the starting point for **Vesttor Vite**.

### Areas explored

- Building interfaces and interacting with the DOM using JavaScript.
- Authentication with Firebase Authentication.
- Data persistence with Cloud Firestore.
- Creating, viewing, editing, and deleting financial transactions.
- Organizing categories and payment methods.
- Recording installments and displaying financial totals.

### Technologies

HTML · CSS · JavaScript · Firebase Authentication · Cloud Firestore

### Structure and local setup

The frontend is in `public/`. The repository also includes Firebase configuration and experimental files.

To explore the study, clone the repository, review the Firebase configuration, and serve `public/` through a local HTTP server. Authentication and data flows require a configured Firebase project, enabled services, and appropriate access rules.

### Project status

This repository preserves the initial academic version. The features describe the scope explored in the source code, rather than a complete or production-ready financial application. Running it depends on environment configuration and external services.
